# Portfolio Camelia Difi

Portfolio professionnel moderne avec animations 3D et design minimaliste.

## Portfolio accessible sur : 


```bash
https://camelia-difi.com/
```

## 🚀 Technologies utilisées

- **React** - Framework UI
- **Vite** - Build tool
- **Tailwind CSS** - Framework CSS
- **Three.js** - Animations 3D
- **Lucide React** - Icônes

## 📦 Installation

1. Cloner le repository
```bash
git clone https://gitlab.com/Cams213/portfolio.git
cd portfolio
```

2. Installer les dépendances
```bash
npm install
```

3. Lancer le serveur de développement
```bash
npm run dev
```

Le site sera accessible sur `http://localhost:5173`

## 🏗️ Build pour production

```bash
npm run build
```

Les fichiers optimisés seront dans le dossier `dist/`
